# Phase 05 — Refactor (선택)

`/dflow-dev` 의 Refactor 서브에이전트가 읽는 파일이다(supervised 만 — 무인 실행에서는 띄우지 않는다). 커밋·읽기·병렬
조사·포그라운드·무거운 명령·토큰 규칙은 프롬프트(phase-prompt.md 템플릿)에 있다.

- 동작 변경 금지 — 중복·네이밍·구조만. 끝나면 전체 스위트 재실행, 기준선 회귀 = 실패
  (이때 Refactor 커밋만 되돌린다. Build 산출물은 커밋 경계로 보호돼 있다).
- 고칠 것이 없으면 커밋하지 않고 그렇다고 보고한다. 그때는 Refactor 게이트가 돌지 않는다.
- 테스트를 지우거나 skip 해 초록을 만들지 않는다. 테스트 총수 감소 = 게이트 실패다.

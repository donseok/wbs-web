## 수정요청사항

### 요청 대상

- 개발팀팀

- 완전자동/개발자동/수동 필요
  - 완전자동 : 설계-완료
  - 개발자동 : 설계는 수동(설계문서가 있어야한다.), 개발만 자동
  - 수동 : 모두 사람이 명령  / 직접 코딩/LLM  실행 으로 개발
- WBS에서의 상태, 에이전트의 단계/상태 모두 다르다. 
  - WBS에서의 상태는 실적에 수치를 직접 입력
  - 에이전트의 단계와 상태
- 에이전트 작업중일때 취소를 할 수 있는 기능
- 24시간 자동 실행하는 에이전트 필요
- 위임 켠 채로 단계 고칠 수 있게 할지 생각해보자.
